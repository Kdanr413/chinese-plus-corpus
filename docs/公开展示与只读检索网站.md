# 公开展示、只读检索与本地构建下载

本方案使用同一份完整源码，但启动两个独立入口：私有构建平台默认 `127.0.0.1:8000`，公开展示站默认 `127.0.0.1:8002`。展示站复用现有 BCC 检索与已发布 Release，提供首页、构建流程介绍、源码和模板下载、只读 API；不接入账号管理、上传、模型配置或加工任务。

## 本地体验

在已有构建环境、项目根目录执行：

```powershell
python -m corpus_platform public-site --config configs/public_site.example.json
```

打开 http://127.0.0.1:8002/。示例配置的公开版本列表为空，不会自动公开主机上的任何语料。尚未配置源码 ZIP 时，下载页会显示提示。原构建平台可继续在 8000 端口运行。

## 准备可迁移的只读资产

先在构建平台确认正式发布版本已建立索引，且使用正式话题体系。把下列 `PROJECT_ID`、`CORPUS_KEY` 和 `VERSION` 换为自己的值。命令不会重新加工，也不会覆盖目标已有版本：

```powershell
python -m corpus_delivery.export data/portal/projects/PROJECT_ID/data/releases/CORPUS_KEY/VERSION data/public_site/releases
python scripts/maintenance/build_source_release.py --output deliveries/public-source-001
New-Item -ItemType Directory -Force data/public_site
Copy-Item configs/public_site.example.json data/public_site/settings.json
```

源码发行目录必须是尚不存在的新目录。它生成完整源码 ZIP、`release-manifest.json` 和校验记录，不包含实际语料、账号或密钥；该源码包本身也包含公开站点功能。不要把整个项目压缩后作为公开下载文件。

修改 `data/public_site/settings.json`：

```json
{
  "site_title": "我的领域语料库",
  "description": "检索已发布语料，下载构建方法与程序。",
  "corpus_title": "领域语料库",
  "release_root": "data/public_site/releases",
  "allowed_releases": [{"corpus_key": "CORPUS_KEY", "version": "VERSION"}],
  "source_archive": "deliveries/public-source-001/corpus-source.zip",
  "repository_url": "https://github.com/Kdanr413/chinese-plus-corpus",
  "repository_requires_access": true,
  "usage_notice": "请在此填写真实的语料引用、代码许可及使用范围说明。"
}
```

所有相对路径均以项目根目录为基准，可整体搬迁；`CORPUS_KEY` 对应 Release 的 `corpus_id`。列表只开放明确列出的版本，空列表不开放语料。更换公开版本时编辑此私有配置并正常重启展示服务，不覆盖历史 Release。配置文件保存在忽略提交的 `data/` 下，不随源码分发。示例配置可公开，实际配置不需要提交 GitHub。

`source_archive` 所在目录必须同时保留发行脚本生成的 `release-manifest.json`。服务启动和下载时检查 SHA-256、长度及敏感文件路径，包被修改后停止提供下载，需管理员检查并重启。校验通过不等于自动获得代码或语料许可，发布者仍需明确授权范围。当前 GitHub 为私有仓库，公开站 ZIP 下载无需 GitHub 账号；仓库链接仅对已获权限者可用，不会自动更改仓库可见性。

```powershell
python -m corpus_platform public-site --config data/public_site/settings.json --host 127.0.0.1 --port 8002
```

首页显示选定版本、三级话题数和来源文档数。检索页显示至少 4 字符的前十领域术语，完整统计可下载；话题体系显示三级话题及标志词。来源筛选读取发布时冻结的元数据，历史未登记的来源仍为未分类，需要在原构建项目补录并发布新版本后更换公开版本，不能直接修改冻结资产。

## 页面和 API

| 地址 | 用途 |
| --- | --- |
| `/` | 公开首页与语料概况 |
| `/search` | 词频、上下文与领域知识检索 |
| `/workflow` | 六步流程介绍 |
| `/download` | 完整源码与输入模板下载 |
| `/api-guide` | API 调用示例 |
| `/api/site` | 公开站点版本与下载校验信息 |
| `/api/v1/corpora` | 公开语料库列表 |
| `/api/v1/kwic?q=储能&limit=10` | 上下文、术语和话题标记 |
| `/api/v1/terms?min_length=4&page_size=10` | 至少 4 字符的前十术语 |
| `/api/v1/terms/export` | 完整术语 CSV |
| `/api/v1/topics?level=3` | 三级话题与标志词 |
| `/api/v1/annotations?page_size=20` | 已发布逐句标注 |
| `/api/v1/sources` | 来源类别和教材目录 |

参数及返回格式见 [检索与标注 API](检索与标注API使用说明.md) 和服务 `/openapi.json`。程序调用示例：

```python
import requests
base = "http://127.0.0.1:8002"  # 部署后替换为实际 HTTPS 域名
r = requests.get(base + "/api/v1/kwic", params={
    "q": "储能", "limit": 10, "source_category": "教材"
}, timeout=30)
r.raise_for_status()
print(r.json())
```

公开服务没有门户分享链接的登录、有效期或按人撤销功能，能够访问网站的人可查询明确开放的版本及逐句标注。仅提供查询结果与统计导出，不提供整库正文或原始文件下载，也不自动把网页跨域权限开放给所有第三方网站。其他程序可以直接使用 HTTP API；需要浏览器跨域调用时由部署者按具体域名配置。

## 搬到服务器

服务器只需要源码、一个或多个选定 Release、私有站点配置、经过校验的源码 ZIP 与发行清单。无需搬账号数据库、模型、清洗缓存、历史轮次或原始语料。源码、结构化语料与索引仍是独立资产；从发布包保持完整复制，不能只复制 HTML。

Windows x64 / Python 3.11 为当前已验证的原生 BCC 环境。可用专用 Python 环境安装 `requirements-public.txt`；不需要 PostgreSQL 服务、BERTopic 或 GPU。此文件是只读运行依赖清单，新服务器仍须实际验收原生 BCC 导入和真实检索。Linux/Docker 的原生库兼容性尚未验收，不保证直接迁移成功。

部署配置、启动脚本和 HTTPS 入口见 [公开站部署](../deploy/public/README.md)。当前阶段仅搭建和验证本地公开站，不自动开放公网。公开站放在服务器后，下载者在个人电脑安装完整构建环境；他们自己的加工不会占用公开站资源。

## 检查和备份

启动时会验证所选 Release 的资产完整性和索引状态，缺失或校验失败会拒绝启动。正式语料体系不能标记为测试体系。`/health` 检查服务响应，真实词频与例句查询才验证原生索引。

保留公开资产、站点配置、源码 ZIP 和发行清单的备份。更新源码包使用新的发行目录，更新语料使用新的 Release。回退只需要将站点配置指回已保留的版本后正常重启展示服务，不改变私有构建平台。
