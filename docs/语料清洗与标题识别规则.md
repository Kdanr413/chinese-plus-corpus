# 语料清洗与标题识别规则

## 1. 目标

清洗程序面向教材、政策文件和网页爬虫文本，输出可追溯的文档、章节、段落和句子级语料。处理原则是保守识别标题、按来源抽取正文、记录删除量，并保留原文件路径供复核。

## 2. 爬虫正文抽取

爬虫 TXT 中的 `TITLE`、`URL`、`DATE` 首先作为元数据读取，不再把文件哈希名当作标题。正文按以下顺序确定：

1. 优先寻找“正文”等显式起点；
2. 否则从正文区再次出现的文章标题之后开始；
3. 遇到“相关文章、相关阅读、最新新闻、友情链接、采购头条、版权信息”等尾部标记时停止；
4. 删除导航、登录、打印、字号、收藏、站点代码、服务热线等模板行；
5. 主页、栏目列表页、正文过短页和领域相关性不足的文章不进入语料库。

领域相关性同时参考标题命中、正文中不同领域词的数量、总命中次数和单位长度密度，避免综合报告因偶然提到一次“新能源汽车”而被整体保留。

## 3. 练习内容与重复页眉

教材中的“练习、习题、复习题、思考题、自测题、选择题、判断题、填空题、简答题、计算题、实训”等块按段落结构删除，并在文档元数据中记录 `exercise_paragraphs_removed`。

短文本若在同一文档中高频重复、位置呈现页眉特征，则作为重复页眉删除，并记录 `running_headers_removed`。该规则不删除正常长段落。

## 4. 标题识别

只有满足明确标题格式且未触发正文否决条件的文本才被识别为标题。支持的主要格式包括：

- “第X章/节/部分”且带有简短标题文字；
- “一、”“（一）”等短标题；
- “1.1”“2.3.1”等具有层级点号的短标题；
- 简短的法律条目标题；
- 附录、前言等固定标题。

以下内容不得识别为标题：

- 日期、时间和日期时间组合；
- 纯数字、页码、比例、金额及表格数据行；
- 带目录点线和尾部页码的目录项；
- 以句号等终止标点结尾的完整陈述句；
- 过长的法律条款或编号正文；
- 只有“第1章”而没有标题文字的残片；
- 数字组过多、正文符号过多或以连接词结尾的行。

每个标题保存 `heading_rule` 和 `heading_confidence`，便于在 `heading_cleaning_audit.csv` 中抽样核验。

## 5. 质量验收

每次修改后至少执行：

1. `tests/test_corpus_cleaning.py` 中的标题与网页边界单元测试；
2. 完整语料重跑并检查清洗报告；
3. 对日期、长句、数字行和网页模板词做反向检索；
4. 抽查各来源清洗文本及标题审计表；
5. 重建话题候选，确认聚类使用章节直接正文而不是父章节汇总正文。

`clean_text_by_source` 完全由清洗脚本生成。每次完整重建时程序会先删除并重建该子目录，防止已经被新规则淘汰的文档 TXT 残留；原始语料目录不会被修改。

自动删除和自动标题识别都不是不可逆的人工裁决；原始路径、来源 URL、规则、置信度和统计信息必须保留，以支持回溯和规则迭代。
