# 三级话题体系构建指导

## 目标

从当前语料建立稳定、可解释的“一级 > 二级 > 三级”领域话题体系，然后用它标注全部句子或完整对话话轮。

## 输入在哪里

- 清洗语料：`data/processed/corpus/`；
- 可选参考体系：`configs/topics/new_energy_candidate_taxonomy.json`；
- 任务工作区：`data/workspaces/chinese-plus/topic-workflow/`。

参考体系是候选知识，不是必须强制匹配的最终答案。没有合适节点时允许提出新话题。

## 当前流程

1. 把记叙文拆为完整句子，把对话体拆为完整说话人话轮；
2. 统计有效单元数 `N`，固定抽取 `ceil(N/3)`；
3. 从样本发现候选话题；
4. 多个模型分别判断名称、定义和三级路径；
5. 人工只裁决冲突、新话题和层级问题；
6. 发布正式体系；
7. 使用正式体系标注全量 `N` 个单元。

BERTopic、语义聚类或规则方法都只能用于“候选发现”，不能单独决定正式话题，也不能替代人工冲突裁决。

例外是操作台中明确标记的“BERTopic 测试直发”：它只为验证后续全量标注、结构化和发布链路服务，会跳过模型与人工环节，并将结果标记为 `test_only`。正式语料库发布不得使用该捷径。

## 层级原则

| 层级 | 回答的问题 | 示例形式 |
| --- | --- | --- |
| 一级话题 | 属于哪个大的领域方向 | 新能源技术 |
| 二级话题 | 该领域中的哪个对象或任务 | 新能源汽车 |
| 三级话题 | 当前句子具体讨论什么 | 动力电池系统 |

不要把“新闻、教材、报告、问答、课堂练习”等文体或来源当作领域话题。名称应稳定、可复用，定义应说明包含和排除的边界。

## 最终输出

- 正式体系：`data/curated/topics/taxonomy.json`；
- 全量标注：Recognition Workspace 的 `08_approved_resources/sentence_labels.jsonl`；
- 结构化语料中的字段：一级话题、二级话题、三级话题。

具体人工操作见 `话题审核操作说明.md`。
