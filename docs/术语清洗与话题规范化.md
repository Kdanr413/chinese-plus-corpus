# 术语清洗与话题规范化

新能源离线规则整理入口：`python -m corpus_recognition.resource_curation --terms 原术语CSV --taxonomy 原话题JSON --annotations 原标注JSONL --output 新目录`。程序要求输出目录尚不存在，保留输入，不写入旧Release。

输出可上传规范术语表（含score/reference_score、原编号、原标注频次和处置理由）、明确排除表、存疑表、全层级话题CSV、可上传nodes JSON、仅三级可分类节点JSON以及旧新对应表。原提取得分是排序参考，不是正确概率；存疑项不进入正式词表，避免把未确认词直接标注为专业术语。规则为新能源保守词素、前缀和完整词尾规则，并非适用于所有领域的通用清洗器。

结构规范化保留已有主题语义和编号，修复格式和父子关系，补齐各级标志词；不自动合并近义主题，不调用模型重新判定语义。分类选择三级节点，通过父路径呈现一级和二级。

检索页默认请求完整体系，以可展开树展示一级、二级、三级，展示各自定义、标志词与标注计数。旧发布版上级未保存标志词时，页面从其下级汇总并明确标注来源；此展示不修改冻结元数据。直接标注数和含下级标签数区分，多标签可能重复计数。

整理输出是待使用的新资源，不自动更换既有项目或旧句子标注。需要按新术语重新标注时，在新轮次使用新表并发布新Release；保留旧版用于科研追溯。接口 `/api/v1/topics` 默认level=0返回全部层级，也支持level=1/2/3单层查询。
