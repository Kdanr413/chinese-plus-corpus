基础地址 Base URL本机开发环境为 http://127.0.0.1:8000。公网部署后替换域名，路径保持不变。
数据格式 JSON查询接口返回 JSON；下载接口返回 TXT、CSV、JSONL 或 ZIP 文件。
权限 Authentication公开检索接口可直接调用；操作台写接口在未配置令牌时仅允许服务器本机访问。
推荐给其他使用者的稳定入口：先调用 GET /api/v1/corpora 和版本接口确定检索对象，再调用 GET /api/v1/search 或 GET /api/v1/kwic。带有“操作台内部接口”的 API 主要服务本机管理页面，不建议第三方程序长期依赖。
