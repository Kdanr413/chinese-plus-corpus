# 全流程运行与迁移指南

## 本机启动

推荐双击 `启动语料库平台.cmd`。命令行方式：

```powershell
conda activate corpus-platform
Set-Location D:\production\corpus
python -m corpus_platform doctor
python -m corpus_platform serve --setup
```

首次使用在启动窗口创建账号，密码为 3 至 128 个字符；已有账号后直接网页登录。

双击入口会先访问健康检查：已有健康服务时直接打开操作台；没有服务时优先使用 `corpus-platform` Conda 环境启动。入口窗口不会在错误发生后立即消失。首次启动后请保持服务控制台窗口打开；再次双击只负责重新打开网页，可以按任意键关闭第二个提示窗口。

访问：

- 统一登录与项目入口：`http://127.0.0.1:8000/`
- 登录后打开项目工作台：`http://127.0.0.1:8000/p/<项目UUID>/`
- 项目 API 文档：`http://127.0.0.1:8000/p/<项目UUID>/docs`（需项目所有者登录）
- 健康检查：`http://127.0.0.1:8000/health`

## 用户项目的保存位置

默认每个项目独立保存在 `D:\production\corpus\data\portal\projects\<项目UUID无连字符>/`。从网页工作台地址取得 UUID，去掉连字符即可定位文件夹。账号与项目归属存于 PostgreSQL，文件夹不按用户名命名。

项目目录包含各自上传语料、处理结果、构建轮次、正式 Release、配置与日志。详细表见 [多用户文件位置说明](../corpus_portal/README.md#每个用户的文件保存位置)。第 6 步可以生成和撤销只读检索链接；无需另启服务。

## 运行前检查

```powershell
python -m corpus_platform doctor
python -m corpus_platform status
```

这些管理员命令默认检查原主项目，不自动切换到某个登录用户的项目。用户构建和发布应从自己的网页工作台执行。

确认 Conda 环境、配置、PostgreSQL、数据根目录和端口正常。数据库密码只放在 `.env`。

## 发布前检查

网页会完成大部分操作。命令行维护时，先预演：

```powershell
python -m corpus_platform publish --version 1.0.0 --dry-run
```

确认 `will_overwrite=false`、输入语料和目标路径正确后才能正式发布。发布流程会创建 Workspace、结构化语料、BCC 索引、manifest、Release 和可选 Registry 登记。

## 验证 Release

```powershell
python -m corpus_platform verify --corpus-id chinese-plus --version 1.0.0
```

验证会比较 manifest、文件数量、大小和 SHA-256。失败时不要直接修改 Release，应从旧版本创建新 Workspace。

## 迁移到新电脑或服务器

需要复制：

- 整个项目目录；
- `data/raw/`、`data/releases/` 和需要继续的 `data/workspaces/`；
- 全部多用户项目存储 `PORTAL_STORAGE`（默认 `data/portal/`）和干净模板 `portal_template/`；
- PostgreSQL 备份（含账号、项目归属、各项目管理数据和分享授权）；
- 本机 `.env` 的值应在新机器重新填写，不通过 Git 传递。

迁移后：

1. 创建 `corpus-platform` Conda 环境；
2. 安装 PostgreSQL 或配置远程 PostgreSQL；
3. 设置 `CORPUS_PROJECT_ROOT`、`CORPUS_DATA_ROOT` 和 `DB_*`；
4. 运行 `doctor`、`status` 和 Release 校验；
5. 启动统一平台，打开 `/health`，登录后打开项目工作台和项目内 `/docs`；
6. 用一个只读查询确认 BCC 索引可加载。

Docker 配置位于 `deploy/`，当前 Windows 开发不依赖 Docker。正式公网部署还需要反向代理、HTTPS、备份和访问控制，未经确认不自动执行。

迁移需保持项目 UUID 与目录、数据库归属记录匹配。分享链接读取原项目正式版本；只复制正文文件不能恢复账号与原分享链接。主说明见 [根目录 README](../README.md)，完整服务器步骤见 [部署说明](../deploy/portal/README.md)。
