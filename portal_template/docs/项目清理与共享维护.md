# 源码交付与文件保护

当前个人电脑和服务器均从 GitHub 拉取相同完整源码。唯一最终发行内容为完整源码目录、源码 ZIP、SHA256SUMS.txt 和发行记录。安装步骤见发行包安装说明.md，源码打包工具见 ../scripts/maintenance/README.md。

清理范围仅为已经被新发行替代的 deliveries/2026-10-09、临时生成的旧源码包、旧三部分便携打包工具和验证生成缓存。保留实际程序、必要资源、现用说明、部署文件、输入模板、测试、许可证、Git、.env、日志与当前验收记录。

严禁清理 data/raw。此次也不删除整个 data 目录内的任何文件，包括 data/portal/projects 用户项目、正式版本、原件和过程；不进行数据库删除操作。只读比较原件哈希可用于确认数据没有变化。

SOURCE ZIP 只是源码，不是数据备份。用户资产和数据库始终由主机保管，不上传 GitHub。后台进程使用的模板目录不整体删除；更新模板只能影响新项目，当前用户项目源码保持原样。

清理目录前核对绝对目标必须位于已确认的 deliveries 内，拒绝指向项目根目录、data、.git、.env、配置或任何外部路径。发行工具拒绝覆盖既有输出目录，维护者不得用自动递归删除解决该限制。
