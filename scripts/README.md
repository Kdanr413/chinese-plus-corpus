# scripts

底层算法和兼容脚本。普通用户不直接运行这里的文件，而是使用网页、`python -m corpus_platform` 或各 `corpus_*` 公共模块。

| 目录 | 作用 |
| --- | --- |
| `collect/` | 网页采集 |
| `prepare/` | 盘点、清洗和清洗审计 |
| `topics/` | 旧话题算法与兼容工具；当前主流程由 `corpus_topic_workflow/` 编排 |
| `terms/` | 术语算法和兼容工具 |
| `workflow/` | 分词、结构化、句法树、质量和阶段报告 |
| `maintenance/` | 重建干净构建、成果容器与只读检索发行包；不覆盖已有目录 |
| `verify/` | 管理员显式运行的真实多用户构建验收工具；使用测试句法接口，见验收说明 |
| `ui/` | 旧兼容服务代码；当前页面入口是 `corpus_api/` |

跨模块调用应依赖 `corpus_*.__init__` 暴露的公共接口，不直接绑定脚本内部路径。
