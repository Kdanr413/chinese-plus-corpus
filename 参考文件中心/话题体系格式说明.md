# 参考话题体系上传格式

从 [最小模板](模板/参考话题体系.json) 复制后填写，或参照 [农业完整示例](模板/参考话题体系_填写示例.json)。示例只说明格式，不是对你语料的分类结论。文件保存为 UTF-8 JSON，扩展名 .json，上传到自己项目工作台的“参考话题体系”。旧版平面 CSV 与 dynamic_topic_taxonomy.json 不能作为这一入口的上传模板。

| 字段 | 规则 |
| --- | --- |
| taxonomy_name | 建议填写体系名称 |
| taxonomy_version | 必填，非空版本标识，如 1.0 |
| classification_object | 必填，说明分类对象 |
| root | 必填，一个根节点对象 |
| id | 所有节点必填且全局唯一，建议使用英文字母、数字和下划线 |
| name | 所有节点必填且非空，作为话题名称 |
| definition | 建议填写边界定义 |
| representative_keywords | 关键词字符串数组，如 ["水稻", "稻田"]；无关键词写 [] |
| children | 子节点对象数组；叶节点写 [] |
| boundary_candidates | 可选，边界候选节点数组；没有写 [] |
| cross_cutting_dimensions | 可选，横向维度节点数组；没有写 [] |
| excluded_label_types | 可选，不进入主话题树的标签数组；没有写 [] |

推荐“根领域 → 一级话题 → 二级话题”，根节点也算一级结构。不要把 > 拼进 name 来代替 children；层级路径由程序计算。可选节点与主树也不能重复 ID。JSON 必须使用英文双引号、逗号和括号，不支持注释或末尾多余逗号。

上传校验通过后，生效副本保存在该用户项目的 configs/topics/new_energy_candidate_taxonomy.json，原件保存在项目 data/raw/reference_uploads/。它是人工参考输入；构建、审核后产生的正式体系是另一个文件。网页上传只影响当前项目；文件名可更改，字段结构需保留。
