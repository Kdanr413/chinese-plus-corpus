# 数据目录

| 目录 | 存放内容 | 是否可重建 |
| --- | --- | --- |
| `raw/` | 上传原始语料、网页原件和参考资源原件 | 否，默认永久保留 |
| `interim/` | 盘点、清洗审计和质量中间表 | 是 |
| `processed/` | 当前清洗、语言加工和结构化结果 | 是 |
| `review/` | 仍需导入/导出的兼容人工审核文件 | 视任务而定 |
| `curated/` | 当前正式话题体系、术语表和逐句标签 | 由发布流程更新 |
| `workspaces/` | 可修改的任务和版本工作区 | 可以继续加工 |
| `releases/` | 冻结的长期版本资产 | 否，禁止覆盖 |

普通用户从网页上传和下载，不需要直接移动这里的文件。逐功能位置见 `../docs/功能与文件位置.md`。
